# DiaMate - Smart Diabetes Management

DiaMate is a mobile application designed for Tip 1 diabetes management, helping users track blood glucose, carbohydrates, and calculate insulin doses. 

This project uses **React Native (Expo)** for the mobile frontend and **Node.js, Prisma, PostgreSQL** for the backend.
